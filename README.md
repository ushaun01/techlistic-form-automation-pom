 📘 Project Overview

This project automates the Techlistic Selenium Practice Form using Python, Selenium WebDriver, PyTest, and the Page Object Model (POM) design pattern.

The automation script performs end-to-end form interaction including:

- Text field input
  
- Radio button selection
  
- Checkbox handling
  
- Dropdown selection
  
- File upload
  
- Form submission
  
- Screenshot capture
  
- HTML report generation

This project demonstrates a clean, reusable, and maintainable Selenium automation framework using PyTest and POM architecture.

---

🧩 Features

- Page Object Model (POM) framework design
  
- Selenium WebDriver automation
  
- PyTest framework integration
  
- Explicit waits for synchronization
  
- Dropdown handling using Select class
  
- File upload automation
  
- Screenshot capture after execution
  
- HTML test report generation using pytest-html
  
- Reusable and maintainable methods

# 🚀 How to Run the Project

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/ushaan01/Techlistic-Login-Form-Automation-POM-Project.git
```

---
 2️⃣ Navigate to the Project Folder

```bash
cd Techlistic-Login-Form-Automation-POM-Project
```

---

 3️⃣ Install Required Dependencies

```bash
pip install -r requirements.txt
```

---

4️⃣ Run the Automation Test

```bash
pytest
```

---

5️⃣ Generate HTML Report

```bash
pytest --html=reports/report.html 
```

---

6️⃣ Open the HTML Report

```text
reports/report.html
```
